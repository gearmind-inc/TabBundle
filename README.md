# TabBundle

開いていたタブを、ブックマークに自動で残す Chrome 拡張機能です。

ウィンドウを閉じても、Chrome を終了しても、PC が急に再起動しても、開いていたタブが「その他のブックマーク/TabBundle/自動バックアップ/」に日時のフォルダとして全部残ります。片付けは 1 日 1 回と Chrome の起動時に動きます。自動バックアップのフォルダは、作成から 7 日を過ぎた後の次の片付けで「old/自動バックアップ/」へ移り、old に入ってから 7 日を過ぎた後の次の片付けで削除されます。「手動保存/」は移動も削除もしません。

残したページは、ツールバーのアイコンから開くポップアップでタイトル・URL・本文 (ON にしたサイトだけ) を使って探せます。

## フォルダ構成の例

```
その他のブックマーク/
└ TabBundle/
  ├ 手動保存/
  ├ 自動バックアップ/
  │ ├ 2026-09-25 21:40 ウィンドウ (12 タブ)          ← ウィンドウを閉じたときの分
  │ └ 2026-09-25 09:15 (再起動前) ウィンドウ (5 タブ)  ← Chrome の終了や再起動の前に開いていた分
  └ old/
    └ 自動バックアップ/
      └ 2026-09-17 18:02 ウィンドウ (8 タブ)          ← 作成から 7 日を過ぎた後の次の片付けで old へ移動
```

- 日時のフォルダは上に入ります (新しい物が上)
- 各フォルダの中身は、タブの並び順のブックマークです (同じ URL が何回あっても全部残します)
- Google アカウントの同期を使っていて「その他のブックマーク」が 2 つあるときは、すでに TabBundle がある方を使います。どちらにも無ければ同期される方に作ります
- 注意: `old/自動バックアップ/` に入れたフォルダは、old に入ってから 7 日を過ぎた後の次の片付けで消えます (自分で入れたフォルダは、片付けが最初に見つけた時から数えます)。残したい物は `手動保存/` へ移してください。

## 保存しないタブ

- 固定 (ピン留め) したタブ
- 新しいタブ (`chrome://newtab`)
- 拡張機能のページ (`chrome-extension://`。TabBundle 以外の拡張機能のページも保存しません)
- URL が空のタブ
- シークレットウィンドウのタブ

保存しないタブを除くと 0 タブになるウィンドウは、フォルダを作りません。

## 保存したページを探す (ポップアップ検索)

ツールバーの TabBundle のアイコンを押すと、検索のポップアップが開きます。

- 探す範囲は「その他のブックマーク/TabBundle/」の下の全部です (手動保存/・自動バックアップ/・old/自動バックアップ/ とその中のブックマーク)。TabBundle の外のブックマークは探しません
- タイトル・URL・保存した本文 (下の「本文の保存」を ON にしたサイトだけ) の一部が合えば見つかります
- 空白 (全角の空白も) で区切って複数の言葉を入れると、全部の言葉を含むページだけが出ます
- 大文字と小文字、全角と半角 (「ＡＢＣ」と「abc」、「ｶﾀｶﾅ」と「カタカナ」) は同じ物として探します
- 結果はページごとに 1 行です。URL が完全に同じブックマークだけを 1 行にまとめます (`#` から後ろや、パスが少しでも違えば別の行)。タイトルは一番新しく保存したときの物で、最後に保存した日時が新しい順に並びます
- 行を押すと、そのページを新しいタブで開きます
- 入力中は、打っている言葉を含むドメインが「github.com (42 件)」のように出ます。押すとそのドメインで探します
- まだ TabBundle フォルダが無いときは「まだ保存がありません」と出ます

## 本文の保存 (サイトごとの ON / OFF)

ページの本文 (画面に出ている文字) も検索できるように、サイトごとに本文の保存を ON にできます。

- 初めは全部のサイトが OFF です。OFF のサイトでは、本文を読むことも保存することもしません
- ON / OFF は右クリックのメニューで切り替えます。ページの上、またはツールバーの TabBundle のアイコンを右クリックして「このサイト (github.com) の本文を保存する」を押します
  - ON にするとき、Chrome がそのサイトへのアクセスの許可を求めます。許可しないと ON になりません
  - `http://` と `https://` 以外のページ (`chrome://` など) では押せません
- 「サイト」はホスト名の完全一致です。`github.com` を ON にしても `gist.github.com` は OFF のままです
- ON のサイトのタブでは、アイコンに「ON」の印が付きます
- ON のサイトのページを開き終わるたびに、本文の先頭 2 万字をそのページの URL ごとに 1 つ保存します (同じ URL は上書き)。休止中のタブ・シークレットのタブ・読めないページは保存しません
- OFF にすると、そのサイトの保存済みの本文を全部消し、アクセスの許可も外します。`chrome://extensions` でサイトへのアクセスを外したときも同じく OFF になり、本文が消えます
- 本文は、そのページのブックマークが TabBundle から無くなると消えます (old で期限が来て削除されたとき、自分で消したとき、TabBundle の外へ移したとき)。片付けはブックマークが消えた・移った数秒後と、1 日 1 回の片付けのときに動きます。今開いているタブのページと、閉じた直後でまだ自動バックアップに書いていないウィンドウのページの本文は残します
- 本文はこの PC の Chrome の中 (`chrome.storage.local`) だけに保存します。どこにも送りません (拡張機能は外部と通信しません)。暗号化はしていません

## 使う権限とその理由

| 権限 | 理由 |
|---|---|
| `tabs` | 開いているタブの URL とタイトルを読んで、自動バックアップに残すため |
| `bookmarks` | TabBundle フォルダに書き込み、検索のために読むため |
| `storage` | 控え (閉じる前のタブの一覧)・本文・ON のサイトの一覧を、この PC の中に置くため |
| `alarms` | 1 日 1 回の片付けのため |
| `contextMenus` | 本文の保存を ON / OFF する右クリックのメニューのため |
| `scripting` | ON にしたサイトのページから本文を読むため |
| `unlimitedStorage` | 本文がたまっても保存の上限 (10 MB) で止まらないようにするため |
| サイトへのアクセス (`optional_host_permissions`) | インストール時には求めません。本文の保存を ON にしたサイトだけ、そのときに許可を求めます |

## 開発

```
npm install        # 依存を入れる
npm test           # テスト
npm run typecheck  # 型チェック
npm run build      # dist/ に拡張機能を作る
```

## Chrome への読み込み方

1. `npm run build` を実行する
2. Chrome で `chrome://extensions` を開く
3. 右上の「デベロッパーモード」を ON にする
4. 「パッケージ化されていない拡張機能を読み込む」を押し、`dist` フォルダを選ぶ

## Chrome を終了したとき (⌘Q など)

- Chrome が終わる前に拡張機能が「ウィンドウが閉じた」を処理できたウィンドウは、「(再起動前)」の付かない名前で入ります
- 処理が間に合わなかったウィンドウは、次に Chrome を起動したときに「(再起動前)」付きの名前で入ります
- どちらの場合もタブは残ります

## 取りこぼしの注意

- 最後の変化 (タブを開いた・閉じた・移動した・ページが変わったなど) から最大 2 秒以内にウィンドウを閉じた場合や、Chrome・PC が落ちた場合、その直近の変化は残りません
  - 他の保存 (ブックマークの書き込み) が走っている間は、控えの作り直しがその終わりを待つので、「最大 2 秒」はその分だけ延びることがあります
- 保存したウィンドウが、処理の途中で止まったせいで失われることはありません (二重に残ることはあります)。保存した物は、上の保存期間のとおり自動で片付けます。
- 保存してから約 1 分以内に電源が落ちると、ブックマークの書き込みがディスクに届かないことがあります。その場合は次の起動で確かめて、中身が欠けていたり無くなっていたりしたら、同じ中身のフォルダを新しく書き直します (元のフォルダは消さないので、二重に残ることがあります)
- Chrome が受け付けない URL などで 1 件のブックマークの作成に失敗した場合、そのタブは保存されません。エラーがコンソールに出るだけで、やり直しはしません
- 拡張機能の更新・再読み込み・無効から有効に戻したときは、開いているウィンドウが「(再起動前)」付きで 1 回余分に保存されます (失うより二重に残す方を選んでいます)

## プライバシー

タブ情報と、ON にしたサイトの本文は Chrome 内で扱います。拡張機能は外部へ送信しません。Chrome のブックマーク同期を有効にしている場合、作成したブックマークは Chrome によって同期されることがあります。詳しくは [プライバシーポリシー](PRIVACY.md) をご覧ください。
