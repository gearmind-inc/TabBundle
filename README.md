# TabBundle

開いていたタブを、ブックマークに自動で残す Chrome 拡張機能です。

ウィンドウを閉じても、Chrome を終了しても、PC が急に再起動しても、開いていたタブが「その他のブックマーク/TabBundle/自動バックアップ/」に日時のフォルダとして全部残ります。片付けは 1 日 1 回と Chrome の起動時に動きます。自動バックアップのフォルダは、作成から 7 日を過ぎた後の次の片付けで「old/自動バックアップ/」へ移り、old に入ってから 7 日を過ぎた後の次の片付けで削除されます。「手動保存/」は移動も削除もしません。

## フォルダ構成の例

```
その他のブックマーク/
└ TabBundle/
  ├ 手動保存/
  ├ 自動バックアップ/
  │ ├ 2026-09-25 21:40 ウィンドウ (12 タブ)          ← ウィンドウを閉じたときの分
  │ └ 2026-09-25 09:15 (再起動前) ウィンドウ (5 タブ)  ← Chrome の終了や再起動の前に開いていた分
  └ old/
    └ 自動バックアップ/
      └ 2026-09-17 18:02 ウィンドウ (8 タブ)          ← 作成から 7 日を過ぎた後の次の片付けで old へ移動
```

- 日時のフォルダは上に入ります (新しい物が上)
- 各フォルダの中身は、タブの並び順のブックマークです (同じ URL が何回あっても全部残します)
- Google アカウントの同期を使っていて「その他のブックマーク」が 2 つあるときは、すでに TabBundle がある方を使います。どちらにも無ければ同期される方に作ります
- 注意: `old/自動バックアップ/` に入れたフォルダは、old に入ってから 7 日を過ぎた後の次の片付けで消えます (自分で入れたフォルダは、片付けが最初に見つけた時から数えます)。残したい物は `手動保存/` へ移してください。

## 保存しないタブ

- 固定 (ピン留め) したタブ
- 新しいタブ (`chrome://newtab`)
- 拡張機能のページ (`chrome-extension://`。TabBundle 以外の拡張機能のページも保存しません)
- URL が空のタブ
- シークレットウィンドウのタブ

保存しないタブを除くと 0 タブになるウィンドウは、フォルダを作りません。

## 開発

```
npm install        # 依存を入れる
npm test           # テスト
npm run typecheck  # 型チェック
npm run build      # dist/ に拡張機能を作る
```

## Chrome への読み込み方

1. `npm run build` を実行する
2. Chrome で `chrome://extensions` を開く
3. 右上の「デベロッパーモード」を ON にする
4. 「パッケージ化されていない拡張機能を読み込む」を押し、`dist` フォルダを選ぶ

## Chrome を終了したとき (⌘Q など)

- Chrome が終わる前に拡張機能が「ウィンドウが閉じた」を処理できたウィンドウは、「(再起動前)」の付かない名前で入ります
- 処理が間に合わなかったウィンドウは、次に Chrome を起動したときに「(再起動前)」付きの名前で入ります
- どちらの場合もタブは残ります

## 取りこぼしの注意

- 最後の変化 (タブを開いた・閉じた・移動した・ページが変わったなど) から最大 2 秒以内にウィンドウを閉じた場合や、Chrome・PC が落ちた場合、その直近の変化は残りません
  - 他の保存 (ブックマークの書き込み) が走っている間は、控えの作り直しがその終わりを待つので、「最大 2 秒」はその分だけ延びることがあります
- 保存したウィンドウが、処理の途中で止まったせいで失われることはありません (二重に残ることはあります)。保存した物は、上の保存期間のとおり自動で片付けます。
- 保存してから約 1 分以内に電源が落ちると、ブックマークの書き込みがディスクに届かないことがあります。その場合は次の起動で確かめて、中身が欠けていたり無くなっていたりしたら、同じ中身のフォルダを新しく書き直します (元のフォルダは消さないので、二重に残ることがあります)
- Chrome が受け付けない URL などで 1 件のブックマークの作成に失敗した場合、そのタブは保存されません。エラーがコンソールに出るだけで、やり直しはしません
- 拡張機能の更新・再読み込み・無効から有効に戻したときは、開いているウィンドウが「(再起動前)」付きで 1 回余分に保存されます (失うより二重に残す方を選んでいます)
